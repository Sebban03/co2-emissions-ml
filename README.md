# CO₂ Emissions: Individual Carbon Footprint Prediction

An individual Machine Learning project that analyzes lifestyle-related factors and predicts personal carbon emissions using Python and scikit-learn.

**Project status:** In progress

## Project Overview

The goal is to explore the relationship between lifestyle choices and individual carbon emissions, then build models to estimate them.

The project covers two tasks:

- **Regression:** predicting the numerical value of `CarbonEmission`.
- **Classification:** identifying individuals with high emissions, defined as the top 20% of `CarbonEmission` values.

## Dataset

[Individual Carbon Footprint Calculation](https://www.kaggle.com/datasets/dumanmesut/individual-carbon-footprint-calculation) by Mesut Duman and collaborators (Kaggle, CC0: Public Domain). The file is included in `data/raw/co2_emissions.csv`.

- 10,000 **synthetic** records: emissions were calculated from weightings taken from various studies and online calculators
- 20 features related to lifestyle, including diet, transportation, energy consumption and waste
- Regression target: `CarbonEmission`
- Classification target: `high_emission` (top 20% of emissions)

Because the target is calculated from the features, high scores here likely reflect how the data was generated, not performance on real-world data.

## Notebooks

1. `01_eda.ipynb`: data quality, distributions and relationships with the target.
2. `02_split.ipynb`: definition of the classification label and stratified train/test split.
3. `03_modeling.ipynb`: preprocessing pipelines and cross-validated comparison of baseline, linear, k-NN, tree-based and boosting models.

## Models and Evaluation

Models compared for both tasks: Dummy baseline, Logistic / Linear Regression, k-NN, Decision Tree, Random Forest and Gradient Boosting. Preprocessing is part of each pipeline, so it is fitted only on training folds during cross-validation.

Main metrics: **PR-AUC** for classification (classes are imbalanced, 80/20) and **MAE** for regression.

### Preliminary Cross-Validation Results

Results obtained with cross-validation on the training set:

| Task | Model | Metric | Result |
|---|---|---|---:|
| Classification | Logistic Regression | PR-AUC | 0.974 |
| Classification | Logistic Regression | F1-score | 0.906 |
| Regression | Gradient Boosting | MAE | 106.4 |
| Regression | Gradient Boosting | RMSE | 147.0 |

Baseline results:

- Classification PR-AUC: 0.200
- Regression MAE: 766.0

These results are preliminary. Hyperparameter tuning and the final evaluation on the held-out test set are still planned.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Sebban03/co2-emissions.git
cd co2-emissions
```

2. Create and activate a virtual environment:

**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the notebooks in order:

- `01_eda.ipynb`
- `02_split.ipynb` (creates `data/processed/` with the train and test sets)
- `03_modeling.ipynb`
